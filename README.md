# Blazor DataGrid: Change Freeze Direction Using Custom Column Menu

This is a practical example of using the [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) component with advanced column freezing capabilities. The sample showcases how to implement a custom column menu that allows users to toggle between freezing a column on the left or right side of the grid, providing greater flexibility in data visualization and navigation.

### Key Features

- **Custom Column Menu**: Add custom menu items to the grid's column header context menu
- **Dynamic Freeze Direction**: Toggle between left and right freeze directions at runtime
- **Interactive DataGrid**: Display sample order data with multiple columns
- **Interactive Server-Side Rendering**: Uses Blazor's interactive server-side rendering capabilities

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-datagrid-change-freeze-direction-using-custom-column-menu.git
cd blazor-datagrid-change-freeze-direction-using-custom-column-menu
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
